# Changelog

All notable changes are documented here. This project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-01

### Added

- PostgreSQL v3 wire gateway for policy-selected field-level encryption.
- AES-GCM, opt-in deterministic AES-SIV, HMAC blind indexes and versioned KMS
  key bundles for Vault Transit, AWS KMS, Google Cloud KMS and Azure Key Vault.
- PostgreSQL protocol, policy, cryptography and integration tests; Helm chart,
  signed multi-architecture GHCR release workflow, SBOM and provenance.
